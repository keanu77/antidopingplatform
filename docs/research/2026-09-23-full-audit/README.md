## 方法與失敗處理

使用者同意較便宜的模型，套用獨立中立提示與逐案引用檢核。早期低成本子代理路徑收到403，改用已登入的本機CLI；不宣稱已查明供應商拒絕原因。途中亦有EOF、連線逾時及格式失敗。每次最長600秒，同批同席最多一次重試；第二次失敗改用其他模型家族。47次未通過的歷史批次執行保留，均未列入完成。所有模型程序已結束。

輸入是固定案例主張與官方來源抽取文字，去除先前審核結論，不讓模型看到其他席答案。500件共96批、1,015個逐案來源項目（不等於1,015份不重複文件）；498件另附官方名冊原始列，13份文件使用已保存OCR。模型檢查身分、國家／代表隊、事件、物質、處分、日期、後果、教學結論。每列必須有有效案例ID、完整欄位、逐案來源及可對應行號；缺案、虛構文件ID、無效JSON或狀態矛盾不計完成。結構有效仍不保證內容正確，所有提出疑義另依原文裁定。

這一輪是對既有來源包的獨立對讀，未全量重新搜尋後續上訴或資格狀態。模型沒有網路／檔案工具，不能把其來源比較稱作獨立上網調查。Peter Bol使用官方網頁工具取得的正文；直接HTML下載失敗，沒有宣稱保存原始HTML。UCI動態欄位、公告日期及補充官方來源由編輯階段另核對並記錄。

完整來源包、提示與CLI原始輸出留在忽略目錄 `.cache/full-audit-20260923/`；公開報告只保留最終模型答案、來源網址、雜湊、簡短釋義和行號，不含思考過程或登入資料。CLI牌價估算不等於訂閱帳戶實際額外收費。

## 留下的三項 P2

1. **國家欄的證據類型需要更明確。** 列表稱「國籍」，詳情直接顯示國家，未同步說明「官方運動身分」與法律國籍的差別。252 件接受紀錄以 USADA 公告標題的 U.S. 描述支持美國欄位；這是證據種類偏弱的待補清單，**不代表已證實 252 件國家都錯誤或有人是台灣選手**。Paparella 的 USADA 標題同樣稱 U.S.，但官方出賽名冊列 BRA，而本資料已正確列巴西，顯示不能普遍從該標題推斷代表國。建議清楚標示國家欄定義／依據，必要時補官方選手頁、國家隊或出賽名冊；單純改 UI 名稱不能替代身分核實。
2. **編輯完成檢查與獨立多模型複核要分開。** `audit:completion` 的 complete 能證明接受紀錄、必填 findings 及清冊雜湊符合設定門檻，不能證明另一位審查者讀過原文。本輪實際只有 15 件來源對讀，8 件至少兩席、其中 4 件三席重疊。前輪 README 已揭露核心事實／完整卷宗的界線，故這是完成層級及涵蓋率的限制，不是查獲偽造。
3. **Paparella 的「服刑」用語不妥。** `data/curated-cases.json:20560` 的「原6個月，服刑近3個月後終止」描述的是運動禁賽，容易讓人誤會為刑事監禁。建議改「原禁賽6個月，執行近3個月後終止剩餘禁賽」。這項由主持人加列；[USADA 公告](https://www.usada.org/sanction/flavia-paparella-granted-reduced-sanction/)支持的是禁賽減免，沒有刑事服刑敘述。

詳細位置、驗證與修正建議見 [adjudicated-findings.json](adjudicated-findings.json)。本輪只提出審核結果，尚未套用上述調整。

## 模型分歧與已排除的假陽性

**Jessica Denney Phillips 的 14 個月是本輪主要分歧。** Codex 將其列為尚未獨立讀取官方名冊的細節；Gemini 列為 P1，理由是公告正文沒有 14 個月及完整姓名。我重新查閱 [USADA 官方名冊](https://www.usada.org/results/sanctions/)，確認姓名列 `Denney Phillips, Jessica`、處分列 `14 Month Suspension`，並連到同一個案公告。公開資料原本也明寫「官方名冊列14個月」。原查核方法允許公告與官方名冊互補，因此 **P1 不成立**；正文未列期間的限制仍保留。Gemini 猜測「排版漏字」沒有證據，未採用。

其他裁決：

- **Grok 對 Phillips 的期間疑問**：其輸入公告正文確實未列期間，這個範圍限制成立；主持人再次核對官方名冊仍有 14 個月，故不採用將資料改成「期間未知」的建議。Grok 將此列 P2 待查，與 Gemini 原先提出的 P1 不同。
- **Grok 對 Paparella 摘要的建議**：可把「TUE 與清單變更減刑」改得更明確，避免讀者誤會減免來自追溯 TUE。正文及教育註已說清楚，不列新增核心事實錯誤；可連同上列「服刑」措辭一起調整。
- **Grok 的台灣排除結論不採用**：它一方面承認六件國家身分證據不足，另一方面在表格稱八件皆非台灣、符合條件，超過其提供的證據。沒有證實存在台灣選手，也不能宣稱八件身分都已核實。
- **Grok 對 U.S. 標題的解釋須保留界線**：Paparella 案能反證不能普遍把該標題當成代表國，但不能進一步斷言所有 U.S. 標題唯一意思都是管轄或居所。保留補強身分來源的建議，不因此把其他六件美國欄位判成已證實錯誤。
- **Glasgow 是教練**：資料已有 `Athlete Support Personnel` 及清楚教練敘述；新聞標題稱 Athlete 不構成現有資料誤述。
- **Fischbach 禁賽期出賽但未追加禁賽**：資料已寫僅追加取消成績，沒有做相反的一般化推論。
- **Harbert 退休停算**：主持人新查官方名冊，確有退休停算註記，與資料相符；未硬算固定終日。
- **Licon／Heinzl 的陰性檢體、Oberst 的未來 TUE、Boyle／Qualls 的追加處分、Simmonds 的無過失 ADRV**：模型在其各自抽查範圍內未發現主要敘述衝突。
- **141 件舊案待查**：原 README 已揭露，不能指控被隱瞞或說原報告宣稱所有舊案已完成。
- **Gemini 結論也有過度概括**：來源包只有 Paparella 的 BRA 身分 PDF，以及 Oberst 的 Team USA 頁，不能將其外推成八件均以 PDF 核實國家、已完整證明排除台灣。該模型結論不採用。Gemini 建議國際總會名冊為「唯一」國籍依據也過於絕對；其他明確官方身分來源仍可能適用。

這些差異不是依模型票數決定，而是由原文、資料欄位及新查官方名冊裁決。**共識不等於事實。**

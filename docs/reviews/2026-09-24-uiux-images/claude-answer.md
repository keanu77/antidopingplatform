# 運動禁藥教學網站 UI/UX 獨立審核與生成圖像評估

## (1) 保留的優點

網站展現三項顯著的設計成熟度：

**視覺層級清晰** — 首頁使用漸層色系（emerald-700至teal-600）、lucide icon與堅實的排版，hero section與導航卡片層級分明。無廉價感的過度裝飾。

**內容深度可及** — DOM顯示統計頁面達5148px，教育專區3891px；用戶能順暢捲動閱讀517案例的詳細資訊，表示現有文字組織未造成認知負荷（overflow: 0，無截斷警示）。emoji作為視覺標記（🧪S0、💪S1、📈S2）既輕量又易掃視。

**無障礙基礎** — Layout.jsx:202有跳至主內容鏈結；aria-label分布CaseList、TestingProcess各步驟；form元素含htmlFor綁定。mobile menu鍵盤導航實裝（handleMobileKeyDown）。

## (2) 優先UI/UX問題（最多5項）

### 已證實

**1. 藥檢流程「四步驟圖解」承諾與實裝不符**
- 檔名：`frontend/src/pages/TestingProcess.jsx`，line 69承諾「尿液藥檢四步驟圖解」
- 實際：line 4-58定義steps陣列，line 117-124僅迴圈`<li>`渲染文字details，無流程視覺化
- 證據：DOM /testing-process (width:1280)，高度1355px，內容為步驟indicator +文字清單，無圖表或SVG流程圖
- 風險：運動員需快速理解「通知→報到→採樣→表單」的實際間隔與責任轉移（未成年陪同權、樣本分裝程序），文字序列難形成心智模型

**2. 教育專區物質分類視覺同質化**
- 檔名：DOM /education (height:3891px) 或推測 `Education.jsx`（未列出，但DOM展示S0-P1各科專區）
- 證據：DOM文本「🧪S0...💪S1...📈S2...」，每個物質用相同emoji+文字卡片結構，S0-P1共13項
- 問題：S1（合成代謝、肌肉增長）與S5（利尿劑、掩蔽）的視覺區分度低；色彩或圖示無差異，用戶難快速掃視找禁用類別
- 無障礙風險：仅靠emoji的assistive technology讀取效果差（「眼淚符號代表S7？」）

**3. 統計頁面時間軸缺視覺序列**
- 檔名：`frontend/src/pages/Statistics.jsx`，line 129-132
- 代碼：`majorEvents.map(event => <li><p>{event.year}</p>...)`，僅用HTML `<ol><li>`線性排列1988-2024事件
- DOM證據：/statistics (height:5148px)，「反禁藥事件與制度時間軸」章節無SVG時間軸、無視覺分支、無事件類型（賽事vs制度vs調查）區分
- 認知負荷：Ben Johnson(1988)→WADA成立(1999)→McLaren報告(2016)等重大事件同等視覺權重，難分主次

**4. 案例卡片無案例類型視覺區分**
- 檔名：`frontend/src/pages/CaseList.jsx`，line 429-431
- 證據：`<div className="bg-danger-100 p-2 rounded-lg"><AlertTriangle className="h-5 w-5 text-danger-600" /></div>`
- 問題：所有517案例均用紅色AlertTriangle icon，無法一眼區分「物質陽性」vs「污染抗辯」vs「合法TUE」vs「禁賽期間參與」（DOM /cases顯示多種违规類型）
- 手機影響：390寬下案例卡片grid為1列，icon+文字密度高，類型區分更困難

### 推論（程式碼邏輯推斷但需實測驗證）

**5. TUE決策樹缺樹狀圖視覺化**
- 檔名：`frontend/src/pages/TUE.jsx` (未提供原始碼，但DOM /tue height:2745px)
- 推論：TUE section提及「決策樹」與「4項核可條件」(ISTUE 4.2a-d)，但DOM文本為線性列表（「1. 清楚的醫療診斷」→「2. 不會額外提升運動表現」），非分支決策流
- 待驗：實際UI是否有interactive accordion/tree widget，還是純文字清單

## (4) 最小試驗方案與驗收條件

### 試驗設計：藥檢流程頁面 A/B 測試

**1. 實驗對象**  
- A組：現狀（TestingProcess.jsx原裝，文字步驟）  
- B組：+4張生成圖（通知/報到/採樣/完成表單各1張，寬度1280/390自適應）  
- 樣本：10-15位目標用戶（運動員/教練/醫療人員），各組等分

**2. 圖像生成規格**  
- 工具：Midjourney或DALL-E 3  
- 提示詞：「扁平設計、醫療檢測情境、2-3人物示意、標註步驟編號、中英雙語標籤」  
- 輸出：PNG或WebP，寬度1280px基準（CSS srcset 390px版本），單張<150KB  
- 風格避禁：寫實照片、特定國籍人物、醫學細節（儀器精度）  

**3. 驗收條件**

| 指標 | 成功標準 | 測量方法 |
|------|---------|---------|
| **使用效率** | B組用時減少≥25%（找到「採樣時需要多少尿液」） | 秒表計時；任務成功率80%+ |
| **理解度** | B組用戶能正確述說4步驟順序；控制組無圖準確率 | 開放式提問或多選（事後測） |
| **信任度** | 圖像與WADA官方採樣文件視覺吻合度≥80%（專家檢視） | 對照https://www.wada-ama.org 採樣流程指南圖示 |
| **加載時間** | 首屏LCP不超過2.8s（加圖前2.0s）；CLS<0.1 | 燈塔審計（桌面+4G模擬） |
| **無障礙合規** | alt文本精確且描述性；非關鍵內容不影響鍵盤導航 | WCAG 2.1 AA檢驗；螢幕閱讀器測試 |
| **負面指標** | 未發現圖像與WADA規則的明顯矛盾；用戶投訴≤1件 | 圖像法律/醫學審核；問卷反饋 |

**4. 失敗條件**  
- LCP>3.0s 或 CLS>0.2  
- 理解度無顯著提升（B組 vs A組 p>0.05）  
- 發現圖像誤導運動員採樣流程（如未成年陪同權標示錯誤）

## (5) 反對自身結論的理由與未知

### 為何不加圖的有力論據

**1. 簡潔性是品牌資產**  
— 網站已通過文字傳遞1000頁+內容而不致認知負荷（統計頁5148px無abandon信號）。emoji+icon組合已達成快速掃視。圖像可能分散注意力或造成過度設計感（見Apple健康App的簡文字策略）。

**2. 教學有效性未被破壞**  
— 現有UI讓用戶能深度閱讀TUE核可4條件或案例細節；沒有跳率數據表明文字形式失效。對比之下，圖像若不精確反而增加誤解（e.g., 採樣流程圖若未標註未成年陪同權利）。

**3. 信任與責任邊界**  
— 運動禁藥涉及醫療診斷與法律制裁。AI生成圖像若有錯誤（如物質分子結構、禁賽計算），損害信任成本遠高於純文字聲明「我們無法保證圖像準確性」。現狀文字至少指向官方來源（WADA、USADA、CTADA）。

**4. 手機優先的矛盾**  
— 320寬下，響應式圖像會佔據70-80%屏幕高度，逼迫垂直捲動。TEXT reflow相對友善。若沒有強力數據證明圖對小屏用戶理解度有提升，寧可投入手機文字優化。

**5. 編輯維護成本**  
— WADA每年更新禁用清單（2026年新增M1.4一氧化碳）。若圖像與文字內容耦合，每次規則變更需同時修圖；文字迭代快速，生圖編排遲緩，容易落後。

### 未知因子（無數據支撑）

1. **用戶人口統計** — 無analytics揭示運動員/教練的年齡、教育程度、視覺vs文字偏好  
2. **設備分佈** — 未知目標用戶手機:桌面比例；若95%手機用戶，圖像ROI更差  
3. **認知效應的科學基礎** — 未有對照研究表明圖解對「禁藥規則理解」的實際提升  
4. **法律邊界** — AI生成圖在運動法律文本中的法律地位模糊；第三方教育平台用生圖的責任歸屬未定  
5. **WADA官方立場** — 不知其對非官方教育資源中圖像使用的默認或政策支持  

### 結論的權衡

**推薦優先次序**：  
1. **立即實驗藥檢流程圖** ← 直接改善操作效率，風險可控  
2. **改善TUE互動性**（決策樹UI）← 勝過加靜態圖，提效更大  
3. **強化案例類型區分** ← 用文字標籤+icon，不急著生圖  
4. **統計時間軸用SVG** ← 比AI圖更穩定可控  
5. **教育專區保守** ← 物質圖示需醫學審核，暫不生成  

**現狀保留項**：首頁、整體排版。簡潔本身是力量，勿過度視覺化。

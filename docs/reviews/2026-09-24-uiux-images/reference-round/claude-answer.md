# 反禁藥網站圖片配置評估

## 可行的圖片配置與優先順序

**第一批建議（7張，優先級依序）：**

1. **首頁Hero裝飾圖**（1張）：虛構運動員進行多項目運動場景，仿 injury 網站策略，用 avif 格式響應式裁剪（1280px 約 781×354、390px 約 302×180、320px 約 240×140）。Alt 可空或 aria-hidden，純裝飾。優先級最高，視覺衝擊力強，不佔 CTA。

2. **學習卡配圖**（6張）：禁用清單（虛構表單場景）、測驗（答題進行式）、藥檢（流程步驟）、TUE（醫生咨詢虛景）、案例（通用運動員困境虛景，絕不涉案選手肖像）、消息（資訊分享場景）。均為清楚但非寫實插畫風格。

3. **詳情頁流程圖**（可選，後續）：禁藥分類可用簡化圖示，藥檢流程用 SVG 主控數字/箭頭，插畫補充情境。

## 何處不適合

- **案例搜尋/結果列表**：已橫溢 12px（320px），不能加圖；掃視需快，圖片分散注意
- **禁用清單詳細條目**：法規內容，數字、名稱用 HTML/SVG，無需裝飾圖
- **案例詳情中的真實證據部分**：絕不用人物照片；背景資訊、判罰事實只用文字+表格
- **統計頁面**：已用 Chart.js，毋需疊加圖片

## 小螢幕 & 無障礙策略

- **響應式裁剪**（非等比縮放）：Hero 圖在 320px 可裁為正方 240×240，保留運動主體而非全景
- **漸進加載**：用 `loading="lazy"`，Hero 圖優先，卡片圖延遲；AVIF + WebP 分級
- **alt 屬性**：Hero 圖若 aria-hidden，其他圖片寫有意義描述（如「虛構運動員進行跑步測試」），助螢幕閱讀器
- **固定元素相容**：反饋列 149px 已固定，圖片不涉及 z-index 衝突
- **CTA 保護**：Hero 圖應絕對定位或背景圖，CTA（y112 處）始終浮在上層、可點

## 對參考站設計的立場

**支持**：虛構運動群像確實比寫實照片更中立（無涉案風險），響應式裁剪方案成熟。

**有保留**：injury 網站圖片主要支撐「影片」業務（縮圖導航），antidoping 的核心是文字法規 + 互動（測驗），圖片應是選項補充，不強行全卡必配。學習卡若圖片延遲或缺失，文字標題 + SVG 圖示已足；加圖提升美感但非必需信息。

**建議**：從首頁 Hero 開始驗證，若使用者未報告圖片改善測驗完成度或禁藥理解，後續卡片圖片可保守擴展或靜止。無用戶研究支撐時，勿聲稱圖片提升教育效果。

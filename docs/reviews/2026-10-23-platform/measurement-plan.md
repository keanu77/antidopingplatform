# 三角色使用與學習驗證計畫

本文件是可執行的研究方案，尚無真人研究結果。程式測試只能證明指定流程在測試環境可操作，不能填入真實完成率、耗時、學習提升或臨床正確性。

## 九項任務

| 角色 | 任務 | 可觀察的成功條件 |
| --- | --- | --- |
| 選手 | 從首頁尋找藥品查核 | 抵達工具，知道成分、途徑、賽內外與適用年度會影響結果 |
| 選手 | 處理查無資料 | 不把查無或待核對當成允許，找到 TADA／官方諮詢 |
| 選手 | 練習與補學 | 完成測驗、讀錯題來源，能重新說明下一步 |
| 教練 | 找團隊短課 | 開啟 12 分鐘教案，能列出活動步驟 |
| 教練 | 準備賽前清單 | 找到並列印清單，沒有收集隊員健康個資 |
| 教練 | 處理補充品風險 | 知道認證不等於零風險，能指出官方資源 |
| 醫療 | 查用藥條件 | 找到途徑／劑量限制和原始來源，知道工具未核對的資料 |
| 醫療 | 尋找 TUE 資料 | 抵達適用疾病及申請資料，知道核准權在主管 TUEC |
| 醫療 | 回看臨床案例 | 能分辨事實、程序結果、教材建議與未確認欄位 |

先每角色邀請 5 人做可用性訪談（共 15 人，探索性樣本，不宣稱代表所有人）；包含手機、桌面及需要鍵盤／輔助科技的使用者。使用虛構情境，不收集診斷、用藥或識別資料。取得受試者同意後才記錄匿名任務編號、完成／協助／失敗、耗時與誤解；不要錄製個人健康內容。

逐任務保存：角色、裝置／輸入方式、起訖時間、是否需協助、是否把待查誤認允許、來源是否找到、使用者原話（去識別）、嚴重度、修正與重測日期。將高風險誤解優先修正。未觀察到錯誤不等於風險為零。

## 學習及內容驗收

以相同能力的平行題於學習前、學習後及 7–14 天後測量，記錄題組、來源版本、樣本流失及答案變動；只報觀察到的分數和限制，不由單組前後差推定因果。官方課程／證書與站內練習分開。

具名專業審閱另行指派規則內容負責人及臨床審閱人，逐項記錄資格、利益衝突、來源、核對範圍、簽核日期與複核期限。現有 `professionalApproval: not_recorded` 不可因程式測試通過改成 approved。六項待核對藥物、69 題舊題及 517 案補證隊列須依實際證據處理；2027 需完成年度差異審查才啟用。

## 上線後測量

部署記錄保存 SHA、Preview、CI、正式版比對與唯讀 smoke。瀏覽器報告的 navigation timing 與 build gzip budget 是實驗室基線。若要取得 field CWV，先設計不包含查詢字、健康資訊、完整 URL query 或自由文字的資料最小化量測，再分裝置／網路報告 LCP、INP、CLS 的樣本數及第 75 百分位。尚未收集時填「未量測」。自然監測與寄送需要排程執行紀錄及 provider／收件驗證，不能用模擬測試替代。

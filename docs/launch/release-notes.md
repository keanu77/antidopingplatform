這版包含既有的西藥商品與成分查詢、案例搜尋、TUE 情境、角色學習及來源中心。商品查詢聚焦西藥，補充劑安全教育持續保留；明細底部可前往 TADA 核對商品。

首次 GitHub release 補齊安裝文件、MIT 程式碼授權檔、貢獻與私密資安回報指引，並附操作 GIF、完整示範短片與分享圖片。乾淨 Ubuntu 24.04 環境已驗證安裝、建置、本機 API 與前端測試；查詢與教學不需 MongoDB、Cloudflare 帳號或金鑰。

This release packages the existing Traditional Chinese medicine lookup and anti-doping education platform with English setup documentation and demo assets. It does not change medical decision logic. The interface is in Traditional Chinese.

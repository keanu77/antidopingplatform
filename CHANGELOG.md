# Changelog

## v1.0.0 · 2026-10-23

First documented GitHub release of the existing deployed platform.

- Look up Taiwan Western medicines by product, ingredient, or license number and inspect composition and use conditions.
- Explore anti-doping cases, TUE scenarios, role-based learning, quizzes, and source status.
- Retire herbal/supplement product search while preserving supplement safety education and historical source archives.
- Retain the bottom TADA verification link and simplify repeated provenance text in product details.
- Provide Chinese and English READMEs, a working local quick start, contribution/security guidance, and the existing MIT code license as a license file.
- Include a recorded product-lookup demo, shareable video, and social preview artwork.
- Document monthly or quarterly medicine-update candidates that require review before publication.

This repository launch organizes and packages functionality already deployed. It does not change the medical decision logic or promote pending evidence to clinical approval. Data matching coverage is not accuracy. Third-party data and documents retain their original terms.
